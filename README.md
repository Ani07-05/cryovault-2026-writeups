# CryoVault 2026 -- ctrl-alt-elite writeups

Team **ctrl-alt-elite** -- 53rd place, 3740 points, CryoVault 2026 Qualifier (ISFCR, PES University, 10-11 Oct 2026).

This repo is the **full team's** solve set, not just one member's: **Anirudh (the7thdialect,
Captain)** and **vikas1337**, with full method and scripts for every challenge below. All of the
team's solves are here.

Flags are redacted from every top-level summary table in this README -- the per-challenge READMEs
*do* carry the real flag. See `submission/` for the full qualifier writeup (including flags) as
actually submitted to the organizers.

Categories and challenge names below match the official CTFd scoreboard exactly. (A folder here
used to be named `ouroboros`, but that was a misattribution -- it's actually the Draftpad writeup
and has been renamed; see the note below the category tables for the real, still-unsolved
`ouroboros`. Another folder used to be named `earing` -- that was this session's in-chat name for
the challenge; the real CTFd name is `tearing`, renamed to match.)

## Layout

```
<category>/<challenge-slug>/
  README.md     -- enumeration, analysis, exploit, verification (real flag included)
  solve.py / *   -- solver script (original where it survived the session, reconstructed where it ran in an ephemeral scratchpad)
submission/
  CryoVault2026_Writeups.docx  -- the full qualifier writeup as submitted to the organizers (flags included)
```

Each README notes whether the script is the original or a faithful reconstruction of the method actually used.

## Tools used
Python 3, numpy, scipy, gmpy2, python-flint, fpylll + cysignals, pycryptodome, dissect.extfs, scapy, pwntools, Node.js (browser-side source review), curl/xh/jq, netcat, python-h2/hpack/hyperframe, cbor2, docker, androguard, Z3, Unicorn, objdump, openssl, nmap, WSL, Claude Code + OpenCode (AI pair-solvers).
